# そぞろ野帳

**Tokyo sozoro の候補地に、写真と言葉を入れるための作業表。**

台東区・荒川区 **31町字・359地点**。町字ごとに、最北から最近傍でつないだ徒歩順路で並べてあります。

▶ **https://sohmen99.github.io/sozoro-yacho/**

アプリ本体（[tokyo-sozoro](https://github.com/sohmen99/tokyo-sozoro)）とは分けてあります。
これは**現地で集める側**の資料です。集めたものを入れる器と、何件要るかは
[sozoro-db](https://github.com/sohmen99/sozoro-db) にあります。

---

## 1地点につき3つ

写真だけ集めても画面は変わりません。抽選カードに出るのは**ぼかした写真**と**伏せた一行**、
到着画面に出るのが**名前と写真と説明**だからです。同じ人が同じ場所で3つ埋めてください。

| | 中身 |
|---|---|
| **写真** | 横位置1枚。看板より、通りから見た佇まいを。カードではぼかして出るので、色と明るさが伝わればいい |
| **一行** | 正体を伏せたまま「行ってみるか」と思わせる一行。現在は3文を6,052件で使い回している |
| **説明** | 到着後に名前と一緒に出す2〜3行。何の店か、何を作っているか、いつからあるか |

チェックは開いた端末に残ります（localStorage）。住所をタップすると地図が開きます。

## 撮ってはいけない町字

**浅草・上野・雷門・上野公園・西浅草・花川戸。** 混雑除外で候補から消えるので、
撮っても1枚も使われません。実測で確認済み（雷門起点75案・上野起点45案、一度も出ない）。

**谷中・池之端・上野桜木**も外してあります。月係数が11月に1.252まで上がり、
谷中は `0.63 × 1.252 = 0.789` で混雑判定に入る。**発表が秋なら撮り損になります。**

**荒川区は全域が対象です。** 混雑の中心から徒歩30〜67分の帯にあたり、
人を台東区の外へ逃がす行き先そのものなので、優先度はむしろ高い。

## 対象の決め方

「体験する・街を見る・静かに歩く」のうち **`image_url` が空**で、
**抽選に出る町字**にあるもの。営業許可の名簿である「食べる」7,136件は対象外です。

同一地点の重複行は統合してあります（375行 → 359地点）。
業種ごとに1行のデータなので、長尾版画匠は3行ありますが行くのは1回でいい。
写真を1枚入れれば統合先の全行に当たります。

| | |
|---|---|
| `yacho.csv` | 元データ。担当・写真ファイル名・一行・説明の空欄付き |
| `tools/targets.json` | 徒歩順路を計算した中間ファイル |
| `tools/yacho_gen.py` | `python3 tools/yacho_gen.py` で `index.html` を作り直す |
| `db/001_arakawa.sql` | 荒川区を開ける／座標の印を直す／画像を軽くする／teaserの誤配を直す |

### db/001_arakawa.sql

```sh
wrangler d1 export sozoro --output=backup.sql      # 先に控えを取る
wrangler d1 execute sozoro --file=db/001_arakawa.sql --remote
```

DBのコピーに当てて動作を確認済み。入っているのは4つだけで、根拠が確認できるものに限っています。

1. **荒川区のライセンスは CC BY。**「要確認」で伏せられていた253件を開ける。
   区のサイトの `/a017/opendata/` が404なので、東京都カタログ側を出典にする
2. **`coord_quality='chome'` の194件は、実際には建物の座標が入っている。**
   区配布の `131181_cultural_property.csv` と照合したところ、194件すべてが小数5桁まで一致した
   （約85mずれる旧千住製絨所煉瓦塀を除く）。丁目単位なのは所在地の文字列であって座標ではない
3. **画像URLが Wikimedia の原寸。** 実測で1枚2.9MB、3案表示で最大12MB。
   `Special:FilePath?width=640` に書き換える（171件）
4. **「食べる」に寺のteaserが付いている140件**を、食べる用の3文に振り直す

判断が要るもの（コンビニ・チェーン・夜のみ業態の重みづけ、営業時間の既定値、
重複636行の統合）は入れていません。
